# Emo Detector MLOps

Simple MLOps demo: train a KNN classifier with MLflow, serve predictions via FastAPI, and run everything in Docker.

## Project structure

```
mlops/
├── .github/workflows/deploy.yml      # Deploy image in docker Hub
├── app/main.py                       # FastAPI inference API
├── training/train.py                 # Model training + MLflow logging
├── data/training.csv                 # Training dataset
├── model/model.pkl                   # Saved model (generated by training)
├── Dockerfile
└── requirements.txt
```

## Local setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Train the model:

```bash
python training/train.py
```

Run the API:

```bash
uvicorn app.main:app --reload
```

Open http://localhost:8000/docs

## Docker

The image trains the model during build, then starts the API on port 8000 inside the container.

Build and run:

```bash
sudo docker image build -t mlops-img .
sudo docker container run -d --name mlops-ctn -p 80:8000 mlops-img
```

- **Build** — creates image `mlops-img` (trains model, copies app).
- **Run** — detached container `mlops-ctn`, host port **80** → container port **8000**.

Open in the browser:

- http://localhost
- http://localhost/docs

### Useful Docker commands

```bash
# View logs
sudo docker logs mlops-ctn

# Stop and remove
sudo docker stop mlops-ctn
sudo docker rm mlops-ctn

# Rebuild after code changes
sudo docker stop mlops-ctn && sudo docker rm mlops-ctn
sudo docker image build -t mlops-img .
sudo docker container run -d --name mlops-ctn -p 80:8000 mlops-img
```

On Windows (Docker Desktop), omit `sudo`:

```powershell
docker image build -t mlops-img .
docker container run -d --name mlops-ctn -p 80:8000 mlops-img
```

If port 80 is already in use (e.g. XAMPP/Apache), map another host port:

```bash
sudo docker container run -d --name mlops-ctn -p 8080:8000 mlops-img
```

Then open http://localhost:8080

## API

### `GET /`

Health / welcome message.

### `POST /predict`

Request body:

```json
{
  "age": 18,
  "cuts": 5
}
```

Example with curl:

```bash
curl -X POST http://localhost/predict \
  -H "Content-Type: application/json" \
  -d '{"age": 18, "cuts": 5}'
```

Response:

```json
{
  "prediction": 1,
  "message": "The person is emo."
}
```

## Training data

| Column | Description        |
|--------|--------------------|
| `age`  | Person age         |
| `cuts` | Number of cuts     |
| `emo`  | Label (1 = emo, 0 = not) |
