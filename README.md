# Emo Detector MLOps

Simple MLOps demo: preprocess raw data, train a KNN classifier with MLflow, serve predictions via FastAPI, and run everything in Docker. Pushes to `main` build and publish an image to Docker Hub.

## Project structure

```
mlops/
├── .github/workflows/deploy.yml   # Build & push image to Docker Hub on main
├── app/main.py                    # FastAPI inference API
├── preprocess/preprocess.py       # Raw Excel → cleaned training CSV
├── training/train.py              # Model training + MLflow logging
├── data/
│   ├── raw/raw_data.xlsx          # Source dataset (Excel)
│   └── train/training_data.csv    # Cleaned CSV (generated by preprocess)
├── model/model.pkl                # Saved model (generated by training; gitignored)
├── Dockerfile
└── requirements.txt
```

## Local setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Preprocess raw data (requires `data/raw/raw_data.xlsx`):

```bash
python preprocess/preprocess.py
```

Train the model (reads `data/train/training_data.csv`, logs to MLflow experiment `emo-detector`):

```bash
mkdir -p model
python training/train.py
```

Run the API:

```bash
uvicorn app.main:app --reload
```

Open http://localhost:8000/docs

## Docker

The image runs preprocessing and training during build, then starts the API on port 8000 inside the container.

Build and run:

```bash
sudo docker image build -t mlops-img .
sudo docker container run -d --name mlops-ctn -p 80:8000 mlops-img
```

- **Build** — creates image `mlops-img` (preprocesses data, trains model, copies app).
- **Run** — detached container `mlops-ctn`, host port **80** → container port **8000**.

Open in the browser:

- http://localhost
- http://localhost/docs

### Useful Docker commands

```bash
# View logs
sudo docker logs mlops-ctn

# Stop and remove
sudo docker stop mlops-ctn
sudo docker rm mlops-ctn

# Rebuild after code changes
sudo docker stop mlops-ctn && sudo docker rm mlops-ctn
sudo docker image build -t mlops-img .
sudo docker container run -d --name mlops-ctn -p 80:8000 mlops-img
```

On Windows (Docker Desktop), omit `sudo`:

```powershell
docker image build -t mlops-img .
docker container run -d --name mlops-ctn -p 80:8000 mlops-img
```

If port 80 is already in use (e.g. XAMPP/Apache), map another host port:

```bash
sudo docker container run -d --name mlops-ctn -p 8080:8000 mlops-img
```

Then open http://localhost:8080

### Docker Hub (CI)

On push to `main`, GitHub Actions builds the image and pushes `danielgara/mlops:latest` to Docker Hub. Configure repository secrets:

- `DOCKERHUB_USERNAME`
- `DOCKERHUB_TOKEN`

Pull and run the published image:

```bash
docker pull danielgara/mlops:latest
docker container run -d --name mlops-ctn -p 80:8000 danielgara/mlops:latest
```

## API

Health / welcome message.

### `POST /predict`

Request body:

```json
{
  "age": 18,
  "cuts": 5
}
```

Example with curl:

```bash
curl -X POST http://localhost/predict \
  -H "Content-Type: application/json" \
  -d '{"age": 18, "cuts": 5}'
```

Response:

```json
{
  "prediction": 1,
  "message": "The person is emo."
}
```

## Data pipeline

### Raw input (`data/raw/raw_data.xlsx`)

Excel file with columns `age`, `cuts`, and `emo`. The preprocess step:

- Trims column names and drops rows with missing required fields
- Converts `age` to integer years (rounds decimals from Excel)
- Coerces `cuts` and `emo` to integers; invalid `emo` values are dropped
- Keeps rows with non-negative `age`/`cuts` and `emo` in `{0, 1}`

### Training CSV (`data/train/training_data.csv`)

| Column | Description        |
|--------|--------------------|
| `age`  | Person age         |
| `cuts` | Number of cuts     |
| `emo`  | Label (1 = emo, 0 = not) |

Generated by `preprocess/preprocess.py`; used by `training/train.py` for a KNN classifier (`n_neighbors=3`) with MLflow parameter and model logging.
